# Portcullis submission images

## Upload fields

- **Logo:** `portcullis-logo.png` is a 1024 x 1024 PNG.
- **Cover image:** `portcullis-cover.png` is a 1920 x 1080 PNG rendered from the final title slide.
- **Screenshots:** upload all six PNG files in `screenshots/`, in numeric order.

## Provenance

`01-sepolia-deployment.png`, `02-guardian-dashboard.png`, and `03-documentation.png` are captures of public project resources. `04-six-checks.png`, `05-architecture.png`, and `06-self-audit.png` are frames from the final project presentation. They summarize the shipped guard logic and the self-audit results without adding claims beyond the project materials.

The dashboard capture is retained as public UI evidence. It shows the dashboard's state at capture time and is not presented as a populated settlement feed.
