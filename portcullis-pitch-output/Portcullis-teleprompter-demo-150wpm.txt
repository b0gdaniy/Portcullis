Portcullis is a security and compliance firewall for institutional cross-chain settlement.

It sits between a signed message and the receiver. Before value moves, the guard runs six checks. Only an accepted message reaches settlement.

[SLIDE 2]

The receiver is the last line of defense.

Ronin, Wormhole, and Nomad failed in different ways, but each incident ended with a receiver accepting a bad cross-chain message and moving value.

Portcullis adds an independent decision between message arrival and token transfer.

[SLIDE 3]

Before the adapter pays, the guard verifies six things.

The source and signature must be valid. Token, recipient, and value must be allowed. The message digest must be fresh, the nonce exact, and the rate limit intact. Finally, the guard checks local volume or a private policy verdict.

An ordinary rejection changes no receiver state. An authenticated anomaly can latch the breaker.
